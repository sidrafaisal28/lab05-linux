/bin asal folder nahi, /usr/bin ka shortcut (link) hai. Purane programs chalte rahein, is liye rakha gaya hai.
/usr/bin mein zyada tar commands hoti hain (ls, git, python3), jo Ubuntu khud install karta hai.
/usr/local/bin un programs ke liye hai jo tum khud haath se add karti ho, taake Ubuntu ke apne programs se alag rahein.
